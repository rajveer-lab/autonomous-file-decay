Page reference traces captured from real programs or imported from trace files. Select one to see its access pattern.

Each dot is a reference: time runs left to right, page number goes up. Diagonal lines are scans or loops; horizontal bands are hot pages.

Record a program on this machine

Runs the command and captures the pages it touches while it runs.

The command runs with your user's permissions, exactly as if you typed it in a terminal. Only this page can start it: the server listens on 127.0.0.1 and checks a per-session key.

Import a trace file

MSR Cambridge / SNIA block traces (.csv, .csv.gz), Windows Process Monitor CSV exports, Linux blkparse output, Valgrind Lackey logs, strace logs, or a plain list of addresses.

Train the learned policy on your workloads

The first part of each selected trace is replayed under Belady's OPT, which knows the future. At each OPT eviction, sampled pages are labelled with whether they are needed again soon, and a small model learns to predict that from the page's past only.

Traces to learn from

Then simulate the rest of the trace (the part the model never saw) to check it generalises. The Simulate tab does this by default for a model trained on that trace.
