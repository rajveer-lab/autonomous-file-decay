Learned Paging Simulator

Every policy replays the same page references at the same time. The learned policy was trained offline to imitate Belady's OPT; on each page fault it scores a sample of resident pages, evicts the one least likely to be needed soon, and falls back to LRU when the model is unsure or keeps being wrong.
