Kitchen Synchronization Model

A working model of the smart-kitchen order system as the Dining Philosophers Problem. Every chef is a thread, every cooking station is a binary semaphore, and the Kitchen Manager is a semaphore array or a monitor. The chefs below run the case-study code on a small simulated kernel with real semaphore and condition-variable queues.

      Benchmark: the Section 11 experiment in the model

      N = 5, 10 and 20 chefs; 15 dishes each; prepare 1–3 ms; cook 2–5 ms; all chefs start together at a barrier; naive chefs pause 3–6 ms between stations. Each cell averages several seeded runs. Times are simulated milliseconds; kitchen_threads.py measures the same setup on real threads.
